#сущность
Аккаунт пользователя имеет следующие данные для входа:
- Почта
- Пароль
- Привязанные соц. сети
- Дата регистрации
При создании аккаунта тут же создается [профиль](Профиль%20пользователя) и его id записывается в поле аккаунта. Аккаунт пользователя требуется для его входа и проверки прав доступа к страницам сайта. 
Аккаунты без привязанных способов авторизации считаются пустышками
