SoundAlone имеет встроенный плеер для [музыки](Музыка). Он берет музыку из своей библиотеки.
Так же SoundAlone предлагает пользователям как веб сервис, так и приложение для прослушивания.
Для прослушивания музыки нужно авторизоваться и создать [аккаунт пользователя](Аккаунт%20пользователя.md). Авторизованные пользователи могут редактировать свои данные [профиля](Профиль%20пользователя).

На пользователей могут подписаться другие пользователи. Если подписки взаимные, то пользователи считаются друзьями. За взаимодействия пользователей между друг другом отвечает [социальный сервис](Социальный%20сервис.md)
