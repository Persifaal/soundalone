#сервис 
Сервис плеера регулирует плеер, обновляет данные и синхронизирует с данными из сервера, позволяет подключаться к комнатам и слушать музыку с другими. Может автоматически включать [треки](Музыка) которые выбирает пользователь из различных сервисов, например, [сообщений](Отправка%20сообщений)
