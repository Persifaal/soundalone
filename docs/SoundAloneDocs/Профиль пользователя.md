#сущность 
В отличии от аккаунта профиль может существовать отдельно
Как для профиля имеются следующие поля:
- Аватар
- Тег пользователя (Уникальный, отображается в ссылке и указывает на этого пользователя)
- Отображаемое имя (может повторяться у разных пользователей и отображается в сообществе как ник)
- Обложка профиля

Для [социального сервиса](Социальный%20сервис.md) имеются поля:
- Подписки
- Зарегистрирован ли? (если трек опубликован но автор не зарегистрирован)
- Флаг Premium пользователя
- Флаг Moderator пользователя
- Флаг Administrator пользователя
- Флаг Бана пользователя
- Дата бана пользователя

Пользователь может быть музыкантом. Для этого у него есть поля:
- Флаг Musician подтверждающий что пользователь музыкант
- Флаг Approved Musician подтверждающий что музыкант настоящий (отображается как галочка)
Если пользователь музыкант, то ему доступна функция для публикации треков, которые будут выпускаться под его именем

Пользователь может [подписываться на других пользователей или плейлисты](Подписки)
