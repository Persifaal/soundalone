Сервис плейлистов организует создание, редактирование и удаление плейлистов. Всего есть 2 основных типа плейлиста:
- Альбом автора - создается когда автор заливает музыку в библиотеку. Любые треки должны иметь альбом.
- Плейлист пользователя - он содержит музыку которую пользователь добавляет сам из готовых альбомов
## Альбом автора
Альбомы автора публикуются в соответствующей вкладке профиля. Альбом должен содержать более 1 трека. Треки добавленные в альбом автоматически получают обложки этого альбома.

## Плейлист пользователя
Плейлист пользователя это по сути просто массив id треков. Плейлист имеет название, обложку и описание. Он обязан содержать хотя бы 1 трек. Так же может иметь более 1 автора. Если плейлист создан рекомендательной системой в авторах указывается тем для кого он создан и основной аккаунт SoundAlone.
Плейлист может быть:
- Публичным (тогда его можно найти через сервис сообщества)
- Приватным (его будет видеть только автор)
- Только для друзей (его будут видеть только те у кого с автором взаимные подписки)
- Ограниченным в доступе (можно указать какие из друзей будут видеть или не видеть плейлист)
